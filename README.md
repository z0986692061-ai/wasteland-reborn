# 《廢地重建：餘生復甦》Safari 可玩版

這是可直接在 iPhone Safari 開啟的 Three.js WebGL 真 3D 版本，不再使用 Canvas 2D 平面投影。場景使用 PerspectiveCamera、真正的 3D 世界座標、透視深度、方向光與即時陰影；包含遠山、湖水、偏側小路、程序化草地材質、InstancedMesh 立體草叢、樹木、房屋、廢車、鐵桶、木桌與鐵櫃。近景物件會依真實深度產生視差，遠山不會再跟著畫面大幅平移。玩家不能穿過房屋、廢墟、建造物件或湖水區域。提示詞固定在右上並可收合，設定按鈕固定在左上，材料卡放在左上設定區下方。

## 玩法

左下虛擬搖桿移動，右側大面積區域滑動轉動真正的第一人稱 3D 相機；畫面下方會看到第一人稱雙手、撬棍與立體草叢。瞄準廢車、舊木桌、鐵櫃或鐵桶後，按下右下「互動」即可拆解並取得材料。按「建造」可選擇工作桌、小屋、圍牆或燈具，按「放置」在玩家前方建立 3D 物件。天氣按鈕可切換晴天、陰天與小雨，並改變方向光與環境色調；建造和拆解會提高復甦進度。右上「提示詞」可收合，左上齒輪可調整視角靈敏度、鏡頭移動感、提示顯示與重設本機進度。

遊戲資料會保存在目前 Safari 的 `localStorage`，包括材料、已清理物件、建造物件、天氣、復甦評分與蹲下狀態。

## 桌面測試

桌面瀏覽器可用 WASD 或方向鍵移動，滑鼠拖曳場景轉動視角，按 E 互動、B 建造、Esc 關閉面板。手機則使用觸控介面。

## 本地啟動

在專案資料夾執行：

```bash
python3 -m http.server 3000 --bind 0.0.0.0
```

再用 Safari 開啟預覽網址即可。Three.js 核心已放在 `vendor/three.module.js`，因此不依賴外部 CDN 才能啟動；遊戲進度仍保存在 Safari 本機。
